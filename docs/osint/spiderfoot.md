# SpiderFoot

- **Repository:** [smicallef/spiderfoot](https://github.com/smicallef/spiderfoot)
- **Website:** [spiderfoot.net](https://spiderfoot.net/)
- **Category:** OSINT / Automated Reconnaissance
- **Language:** Python
- **Tags:** `osint` `reconnaissance` `footprinting`

## Description

An open-source intelligence automation tool. SpiderFoot integrates with 200+
data sources (search engines, social networks, DNS, dark web) to automatically
collect OSINT on targets — IPs, domains, email addresses, names, and more.

## Features

- 200+ built-in modules
- Correlation engine to connect data points
- Web UI for interactive use
- CLI for automation / scripting
- API for integration

## Usage

```bash
git clone https://github.com/smicallef/spiderfoot.git
cd spiderfoot
python3 -m pip install -r requirements.txt
python3 sf.py -l 0.0.0.0:5001
```
