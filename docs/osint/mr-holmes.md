# Mr.Holmes

- **Repository:** [Lucksi/Mr.Holmes](https://github.com/Lucksi/Mr.Holmes)
- **Category:** OSINT
- **Language:** Python
- **Tags:** `osint` `reconnaissance`

## Description

A complete OSINT tool for information gathering and reconnaissance. Designed
for penetration testers and security researchers to gather domain, IP, and
email information from public sources.

## Usage

```bash
git clone https://github.com/Lucksi/Mr.Holmes.git
cd Mr.Holmes
python3 -m pip install -r requirements.txt
python3 MrHolmes.py
```
