# AdvPhishing

- **Repository:** [Ignitetch/AdvPhishing](https://github.com/Ignitetch/AdvPhishing)
- **Category:** Phishing
- **Language:** Shell / Bash
- **Tags:** `phishing` `advanced`

## Description

An advanced phishing tool with enhanced features over basic phishing frameworks.
Includes multiple template options and advanced tunnel forwarding.

## Features

- Multiple phishing page templates
- ngrok / Cloudflared tunnel integration
- Port masking
- Custom redirect URLs

## Usage

```bash
git clone https://github.com/Ignitetch/AdvPhishing.git
cd AdvPhishing
chmod +x AdvPhishing.sh
./AdvPhishing.sh
```
