## Description

A beginner-friendly, automated phishing tool with 30+ pre-built templates. Creates
fake login pages for popular websites (Instagram, Facebook, Google, etc.) and
serves them over localhost / ngrok / Cloudflared for credential harvesting.

## Features

- 30+ phishing page templates
- Built-in URL shortener integration
- Tunnel support (ngrok, Cloudflared, LocalXpose, Serveo)
- Port forwarding
- Works on Termux, Linux, and WSL

## Usage

```bash
git clone https://github.com/htr-tech/zphisher.git
cd zphisher
chmod +x zphisher.sh
./zphisher.sh
```
