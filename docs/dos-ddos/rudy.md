# rudy

- **Repository:** [rafosw/rudy](https://github.com/rafosw/rudy)
- **Category:** DoS / HTTP Attack
- **Language:** Shell / Python
- **Tags:** `http-attack` `dos` `slow-rate`

## Description

A professional-grade HTTP POST slow-rate attack tool (R U Dead Yet?). Sends
slow HTTP POST requests to exhaust server connection pools — a type of
application-layer DoS that's hard to detect without specialised mitigation.

## Usage

```bash
git clone https://github.com/rafosw/rudy.git
cd rudy
./rudy.sh
```
