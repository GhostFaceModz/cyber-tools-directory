# r4ven

- **Repository:** [spyboy-productions/r4ven](https://github.com/spyboy-productions/r4ven)
- **Category:** GPS Tracking
- **Language:** Python
- **Tags:** `gps-tracking` `location`

## Description

A tool that tracks the GPS location of a target user. Generates a tracking link
that, when opened, captures device GPS coordinates.

## Usage

```bash
git clone https://github.com/spyboy-productions/r4ven.git
cd r4ven
python3 r4ven.py
```
