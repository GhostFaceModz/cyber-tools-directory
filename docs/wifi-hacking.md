# wifi-hacking.py

## Description
Multi-function WiFi hacking tool. Supports monitor mode, handshake capture, WPA/WPA2 cracking with rockyou.txt, custom wordlists, WPS attacks, and integrates with Nmap, Metasploit, Hydra, and more.

## GitHub
- **Repo:** https://github.com/akashblackhat/wifi-hacking.py
- **Stars:** 527
- **Language:** Python

## Features
- Start/stop monitor mode
- Scan networks
- Capture handshake
- Crack handshake (rockyou.txt / custom wordlist / without wordlist)
- Create wordlist
- WPS attack
- Nmap scanning
- Metasploit exploitation
- Hydra brute-force
- Wifiphisher phishing
- Nikto, Netcat, Gobuster, SQLMap

## Installation (Kali/Ubuntu)
```bash
sudo apt-get update && apt-get install git
git clone https://github.com/akashblackhat/wifi-hacking.py.git
cd wifi-hacking.py
sudo python3 wifi-hacking.py
```
