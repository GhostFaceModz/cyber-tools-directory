# hosthunter

- **Category:** Kali Linux / DNS Recon
- **Tags:** `kali-linux` `dns`

## Description

A Kali Linux tool for DNS host discovery. Enumerates subdomains and hostnames
associated with a target domain. Part of the Kali Linux default toolset.

## Usage

```bash
hosthunter -h
hosthunter example.com
```
