# HOUND

## Description
Lightweight information gathering tool that captures exact GPS coordinates of a target device. Also grabs device model, OS, CPU cores, screen resolution, browser info, and ISP data.

## GitHub
- **Repo:** https://github.com/techchipnet/hound
- **Stars:** 1k
- **Language:** Shell/PHP

## Captured Information
- Longitude & Latitude
- Device Model
- Operating System
- Number of CPU Cores
- Screen Resolution
- User Agent
- Public IP Address
- Browser Name
- ISP Information

## Installation
```bash
git clone https://github.com/techchipnet/hound
cd hound
bash hound.sh
```
