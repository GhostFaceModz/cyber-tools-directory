# CamPhish

## Description
Grab cam shots from target phone front camera or PC webcam by sending a phishing link. Includes GPS location tracking, festival/Youtube TV templates, and cloudflared tunneling.

## GitHub
- **Repo:** https://github.com/techchipnet/CamPhish
- **Stars:** 5.1k
- **Language:** Shell/PHP/HTML

## Features
- Festival Wishing template
- Live YouTube TV template
- Online Meeting template (Beta)
- GPS Location Tracking
- Cloudflare Tunnel integration

## Installation (Kali/Termux)
```bash
apt-get -y install php wget unzip
git clone https://github.com/techchipnet/CamPhish
cd CamPhish
bash camphish.sh
```
