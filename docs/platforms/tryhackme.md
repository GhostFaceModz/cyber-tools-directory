# TryHackMe

- **Website:** [tryhackme.com](https://tryhackme.com)
- **Category:** Cybersecurity Education
- **Tags:** `learning` `cybersecurity`

## Description

A popular online platform for learning cybersecurity and ethical hacking through
interactive virtual rooms. Covers everything from beginner Linux basics to
advanced penetration testing, CTF challenges, and real-world attack simulations.

## Features

- Guided learning paths (Pre-Security, Pentest+, Offensive Security)
- Hands-on virtual machine labs
- CTF competitions
- Certifications upon completion
