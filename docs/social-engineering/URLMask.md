# URLMask

- **Repository:** [thecarpetjasp/URLMask](https://github.com/thecarpetjasp/URLMask)
- **Category:** URL Masking / Social Engineering
- **Language:** Python
- **Tags:** `url-masking` `social-engineering`

## Description

A Python program for Linux users to mask (disguise) URLs. Attackers use this
to make malicious links appear legitimate — a core social engineering tactic.

## Usage

```bash
git clone https://github.com/thecarpetjasp/URLMask.git
cd URLMask
python3 URLMask.py
```
