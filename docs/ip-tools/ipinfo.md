# IPinfo

- **Website:** [ipinfo.io](https://ipinfo.io)
- **Category:** IP Data Intelligence
- **Tags:** `ip-data` `api`

## Description

A commercial IP data intelligence service providing detailed information about
IP addresses — geolocation, ASN, carrier detection, company data, and privacy
detection (VPN / proxy / Tor). Offers a free API tier for developers.

## Features

- IP geolocation (city, region, country, coordinates)
- ASN and network details
- Hosting, VPN, Tor detection
- Company / carrier data
- REST API with free tier (1k requests/day)
