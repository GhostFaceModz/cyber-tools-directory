# Grabify IP Logger & URL Shortener

- **Website:** [grabify.link](https://grabify.link)
- **Category:** IP Logging / URL Shortening
- **Tags:** `ip-logger` `url-shortener`

## Description

An online service that functions as both an IP logger and URL shortener. Creates
tracking links — when a target clicks the link, their IP address, user-agent,
and geolocation are captured. Commonly used in social engineering / OSINT
investigations.

## Usage

1. Go to https://grabify.link
2. Enter the URL you want to disguise
3. Generate the tracking link
4. Share the masked link with the target
5. View captured data (IP, browser, OS, location) on the dashboard
