# Rendercam

## Description
Creates fake video call websites (Google Meet, Zoom, Discord) that secretly capture users through their webcam. Includes IP logging, GPS location capture, and cloudflared tunneling.

## GitHub
- **Repo:** https://github.com/render437/rendercam
- **Stars:** 2
- **Language:** Shell/PHP

## Installation
```bash
sudo apt-get -y install php wget unzip
git clone --depth=1 https://github.com/render437/rendercam.git
cd rendercam
bash rendercam.sh
```

## All-in-One Command
```bash
git clone --depth=1 https://github.com/render437/rendercam.git; cd rendercam; bash rendercam.sh
```
