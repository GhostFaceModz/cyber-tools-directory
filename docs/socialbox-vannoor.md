# SocialBox-Termux (Vannoor)

## Description
Social media brute-force attack framework for Termux. Targets Facebook, Gmail, Instagram, and Twitter accounts with wordlist-based password attacks.

## GitHub
- **Repo:** https://github.com/vannoorsab/SocialBox-Termux
- **Stars:** 11
- **Language:** Shell

## Installation
```bash
apt-get update
apt-get install git
git clone https://github.com/vannoorsab/SocialBox-Termux.git
cd SocialBox-Termux
chmod +x install-sb.sh
./install-sb.sh
```

## Run
```bash
./SocialBox.sh
```
